Development Process
Agile SDLC methodology with 2-week sprints across 5 phases.
01
Research & Requirements
Conducted stakeholder interviews with 15 green entrepreneurs and 3 sustainability lecturers. Analysed competitive platforms (ImpactBase, Good Finance, StartSomeGood). Defined user personas, user stories, and functional requirements via Notion.
User Interviews Competitive Analysis Notion
02
UI/UX Design & Prototyping
Created low-fidelity wireframes in Figma across all 5 pages. Developed a comprehensive design system with typography scale, colour tokens, and component library. Ran 2 rounds of usability testing with 10 participants before handoff.
Figma Design System Usability Testing
03
Frontend Development
Implemented responsive HTML5/CSS3/JS website with multi-page SPA architecture. Built interactive components: category selector, idea form, Business Model Canvas, validation sliders, and score dashboard. Focused on accessibility (ARIA labels, keyboard nav).
HTML5 CSS3 Vanilla JS ARIA
04
Backend & API Integration
Built Node.js REST API connecting to Firebase Firestore for idea storage. Integrated OpenAI GPT-4o for structured business idea generation. Implemented Firebase Auth for user accounts. Deployed on VPS with GitHub Actions CI/CD pipeline.
Node.js Firebase OpenAI API GitHub Actions
05
Testing, QA & Launch
Cross-browser testing via BrowserStack (Chrome, Firefox, Safari, Edge). Performance audit with Lighthouse scoring 94/100. SEO optimisation. Security audit. Soft launch to 50 beta users for feedback before full public release.
BrowserStack Lighthouse Beta Testing
06
Deployment & Maintenance
Production deployment on Cloudflare-proxied VPS. Monitoring via Uptime Robot and Firebase Analytics. Weekly sprint reviews with Trello. Hotjar heatmaps drive continuous UX improvements. Monthly feature updates planned.
Cloudflare Uptime Robot Hotjar
